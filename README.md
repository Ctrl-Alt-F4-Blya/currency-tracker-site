# Currency Pulse

**Currency Pulse** — адаптивный сайт-конвертер валют и криптовалют. Проект показывает курсы валют, криптовалюты, конвертацию, график динамики, полезные сервисы и финансовые новости в одном удобном интерфейсе.

## Кратко о проекте

Currency Pulse создан как локальный веб-сайт для быстрого просмотра валютных и криптовалютных курсов. Сайт собирает данные из нескольких источников, показывает конвертацию между валютами, динамику курса и новости.

Проект работает на чистом **Node.js** без внешних npm-зависимостей, поэтому для запуска не нужно выполнять `npm install`.

## Возможности

- просмотр курсов валют к рублю;
- поддержка популярных валют: RUB, USD, EUR, CNY, KZT, TRY, GBP;
- поддержка криптовалют: USDT, BTC, ETH;
- конвертер валют и криптовалют;
- автоматический пересчёт курса;
- обратный курс;
- примерный расчёт комиссий для разных способов обмена;
- график динамики курса;
- блок полезных сервисов;
- финансовые новости;
- резервные данные, если внешний источник временно недоступен;
- адаптивный интерфейс для компьютера, планшета и телефона;
- запуск через `.bat`-файл на Windows;
- ручной запуск через Node.js.

## Как запустить

### Быстрый запуск на Windows

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите файл:

```bat
START_SITE.bat
```

Также можно запустить русскую версию файла:

```bat
ЗАПУСТИТЬ_САЙТ.bat
```

Скрипт проверит наличие Node.js и запустит сайт.

После запуска сайт откроется автоматически. Если браузер не открылся, перейдите по адресу:

```text
http://localhost:3000
```

Если порт `3000` занят, скрипт попробует открыть сайт на порту `3001`.

## Ручной запуск

Для ручного запуска откройте терминал в папке проекта и выполните:

```bash
node server.js
```

или:

```bash
npm start
```

После запуска откройте в браузере:

```text
http://localhost:3000
```

## Важно

В этой версии не требуется установка зависимостей через `npm install`.

Проект работает на чистом Node.js, поэтому ошибки npm, proxy или timeout не мешают запуску.

Если Node.js не установлен, скачайте и установите LTS-версию Node.js, затем снова запустите проект.

## Источники данных

Проект использует несколько источников данных:

- ЦБ РФ — курсы фиатных валют к рублю;
- CoinGecko — данные по криптовалютам;
- Frankfurter — дополнительный источник кросс-курсов;
- Google News RSS — новости по валютам и криптовалютам.

Если один из источников временно недоступен, сайт использует резервные данные, чтобы интерфейс продолжал работать.

```text

│   ├── styles.css          # стили, адаптивность и визуальный дизайн

```

## Основные файлы

### `server.js`

Главный сервер проекта. Он запускает локальный сайт, отдаёт файлы из папки `public`, получает данные по курсам валют, криптовалютам и новостям.

### `public/index.html`

Основная HTML-страница сайта. В ней находятся блоки: главный экран, конвертер, график, сервисы и новости.

### `public/styles.css`

Файл со всеми стилями проекта: карточки, сетка, адаптивность, кнопки, фон, типографика и визуальные эффекты.

### `public/app.js`

Frontend-логика сайта. Отвечает за загрузку данных, заполнение селектов валют, расчёт конвертации, отображение курсов, комиссий, графика, сервисов и новостей.

### `START_SITE.bat`

Файл для быстрого запуска на Windows. Проверяет Node.js, выбирает порт и открывает сайт в браузере.

## Статус проекта
